[The Mental Model]03
[A Library, Not a Monolith]

No single box does every job.

  • FastAPI — the front desk: checks permission, accepts new sources and questions, responds fast.
  • Neon Postgres — the master ledger: records what's owned, by whom, and how far it's processed.
  • The WFQ dispatcher — the fair line manager: decides whose job enters next.
  • Prefect Cloud — the job supervisor: assigns runs, tracks retries, exposes a dashboard.
  • Qdrant — the meaning-based card catalog: finds content by meaning, not keywords.

08 / 24 The lessons, in order.
[Lesson]09
Concurrency

IF NOT EXISTS isn't a race guard.

Two containers booted at once and both ran the same schema DDL, colliding in Postgres's own system catalog. IF NOT EXISTS doesn't protect the instant both builders start together. Fixed with a transaction-scoped advisory lock — one key to the site, returned automatically on commit or crash.

09 / 24 Two builders, one structure.
[Lesson]10
Resilience

Restarting the worker isn't recovering the job.

Docker restarted the crashed worker fine — the process came back. The row it had been embedding stayed stuck; Prefect marked the run "Crashed" but never resumed it. A separate run finished the job three attempts later. Reopening a factory doesn't put the half-finished order back on the line.

10 / 24 The process isn't the job.
[Lesson]11
Rigor

A discovery experiment isn't a resilience proof.

Killing the worker once and watching what happened was a fair discovery question — either outcome was acceptable. The graded requirement is stronger: no source dropped, stale work redelivered, committed stages never repeated. Dropping one package to see what the courier does isn't a delivery audit.

11 / 24 Curiosity vs. proof.
[Lesson]12
Non-negotiables

"Never in the request path" means the whole boundary.

The literal rule — no PDF library in the handler — was satisfied while a live network call to Prefect Cloud still ran inside the request. timeout=0 means don't wait for the flow to finish, not don't wait for the scheduler to answer. A bouncer checking only IDs still lets weapons through the door.

12 / 24 Read the intent, not the example.
[Lesson]13
Review Discipline

Pull one thread, check what else was holding together.

Deleting a direct-Prefect fallback was correct, and it surfaced two more bugs in sequence — a dispatcher that silently never started, then a video path racing it. Four straight review rounds on the same two blocks each found a bug the last round's own fix had just introduced.

13 / 24 4 rounds. 4 real bugs.
[Lesson]14
Environments

A well-formed URL isn't a portable one.

http://localhost:8100/... validated cleanly and curl'd fine from the host — and was unreachable from inside the worker's own network namespace, where localhost means the worker, not the API. Compose's api:8000 won't resolve on Fly either. "It fetched when I tested it" only proves that.

14 / 24 Ask: who fetches this, from where?
[Lesson]15
Constraints

A non-negotiable isn't the place to find an exception.

"This PDF is authored content, not user media — the gitignore rule wasn't meant for it" sounded reasonable and was wrong: the rule read, literally, "media/PDF artifacts are git-ignored," no carve-out for authorship. The real fix regenerates the fixture from a tracked source at boot instead.

15 / 24 Judgment on how, not on whether.
[Lesson]16
Security

Scope the exception to the need, not the category.

The fetcher needed exactly one private address reachable. The first fix allowed all of RFC1918 to get there — safe for that one case, but it let any token-holder probe every other private service on the network. The real fix: allowlist the one hostname, block everything else, pin the connection.

16 / 24 One hostname, not one /8.
[Lesson]17
Correctness

Guarding the last step isn't guarding the state.

The first stale-write guard blocked exactly the transition observed: indexed → failed. It missed that a stale run walks through parsing/embedding first, clobbering indexed before ever writing failed. Fixed by refusing every write once indexed, except a deliberate reset.

17 / 24 Protect the state, not one path to it.
[Lesson · A Benchmark Is Production Code]18
[Measurement Needs Scrutiny Too]

Five ways a benchmark can lie.

  • Separate user IDs isolate ownership, not shared CPU or dispatcher capacity — a "quiet" phase can still be busy.
  • Dropping failed requests before computing p95 turned 39 failures + 1 fast response into a "10ms" result.
  • A metric's name is a contract: recall@10 needs ten real candidates, not the app's default of six.
  • A required threshold can't be a runtime flag — --min-overlap-frac 0 still satisfies 0 >= 0.
  • Resilience needs four kinds of evidence: precondition, intervention, outcome, resume — not just a final "indexed."
18 / 24 A smoke alarm needs a disconnected-sensor test too.
[Lesson]19
Performance

Fixing the bottleneck you found can surface a worse one.

Scaling workers alone barely moved throughput — the real gap was Prefect polling Cloud every 10s against 3s of real work. Fixing that opened N simultaneous cold Qdrant handshakes, which timed out into a 60s×2 retry. Fixing that surfaced CPU oversubscription, then one shared lock serializing unrelated CLIP/BGE calls.

19 / 24 One fix, one new floor to check.
[Lesson]20
Diagnosis

A correct fix that doesn't move the metric means look deeper.

Splitting the CLIP/BGE locks was correct and mutation-tested — and the decoupling ratio barely moved. The real bottleneck wasn't "two models share a lock," it was "bulk ingest and latency-critical search share a lock, regardless of model." Giving search its own always-local embed call is what closed it: 1.09 / 1.03 / 0.89, repeatable.

20 / 24 Model separation ≠ workload separation.
[Lesson]21
Deployment Reality

The code, the image, and the browser are three different apps.

Editing a file doesn't change the container already running — Compose builds a snapshot; src/ui aren't mounted. The same gap recurs a layer down: a PPTX's storage_key correctly keeps pointing at the original bytes for re-parsing, but citations served straight from it handed the browser raw .pptx labeled as PDF.

21 / 24 Grep every other reader of the field.
[Lesson]22
Ranking Quality

Two signals "agreeing" isn't evidence if either is noise.

Fusion boosted a moment whenever a frame and a transcript hit shared a time window — until a frame and a literal [Music] caption tag coincidentally lined up and outranked the real match. Filtering the artifact closed that case; the boost still needed its own confidence floor for the general one.

22 / 24 Coincidence isn't corroboration.
[Lesson]23
Eval Design

An eval metric can be blind to exactly the bug it should catch.

recall@10 stayed green through the entire ranking bug, because the right citation was always present, just buried — a presence metric structurally can't see pure misordering. Adding MRR@6 and re-measuring the same 14 labeled queries showed an identical score before and after: that set never happened to trigger this bug either.

23 / 24 Recall sees presence, not order.
