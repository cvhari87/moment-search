# Domain documentation

This is a single-context repository.

Before exploring an area, read the root `CONTEXT.md` when it exists and any relevant architecture
decision records under `docs/adr/`. These files are created only when the project has domain
language or architectural decisions worth recording; their absence is not an error.

Use the vocabulary defined in `CONTEXT.md`. If proposed work contradicts an existing architecture
decision record, surface that conflict rather than silently overriding the decision.
